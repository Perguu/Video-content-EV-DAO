# SourceFooter

The required last block of every EV+ infographic: where the data came from and what is assumed.

- `source`: data providers with dates. `note`: assumptions, what is not a forecast, risk.
- Mono `footnote` style in `ink-muted`; labels in `ink` bold.
- Handle defaults to `@EVplus_DAO`. You provide `logoSrc` from the Logos group.
