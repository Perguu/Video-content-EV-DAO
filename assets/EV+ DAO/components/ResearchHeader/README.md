# ResearchHeader

The top of every EV+ infographic: mono kicker, claim-style headline, mono subhead, logo top-right.

- `kicker`: uppercase mono, format `EV+ RESEARCH · <SERIES>` (e.g. MARKET CYCLES, POINTS FARMING).
- `headline`: the takeaway as a full sentence, not a topic. One line on a 1920 canvas if possible.
- `subhead`: what the data is and its time range.
- `children`: optional lede paragraph; wrap key figures in `<b>` so they read in `ink`.
- `logoSrc`: pass the logo from the Logos group. You provide the image URL.
