# Logos

- `ev-plus-logo.png`: the primary mark. Pixel "EV+" wordmark in `phosphor` green on a `terminal` black disc with CRT scanlines, 2048 × 2048 px. Use as the X / Telegram avatar, the top-right mark on infographics, and the footer mark beside @EVplus_DAO.
- Keep the black disc. On paper backgrounds place the whole disc; never cut the wordmark out onto a light ground.
- Minimum size 48 px; clear space equal to the height of the "+".
